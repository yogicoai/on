도구 이름을 외울 필요 없이 주문번호·상품명·기간을 함께 입력하면 됩니다. 회사 데이터와 공식 정책 원문을 확인하여 문의 대응에 활용하는 가이드입니다.

1. CS 업무별 질문 방향

실제 문의 상황에 맞춰 아래와 같이 질문할 수 있습니다.

업무 영역질문 예시
주문·배송 상태

“이 주문 결제됐나요?”

“배송이 출발했나요?”

정책·규정 확인

“반품 시 사용한 쿠폰은 어떻게 처리되나요?”

“제주도 배송비 기준은 무엇인가요?”

문의 답변 초안

“이 문의에 대한 답변 초안을 작성해 주세요.”

“유사 문의의 기존 답변을 찾아주세요.”

미답변 문의 확인

“현재 답변하지 않은 문의가 있나요?”

“최근 3일 미답변 문의를 보여주세요.”

리뷰·고객 반응

“최근 리뷰에서 자주 언급되는 내용은 무엇인가요?”

“A/S 관련 문의를 정리해 주세요.”

매장 발송 조회“해당 매장의 어제 발송 내역을 확인해 주세요.”
재고·품절 확인

“이 상품의 품절 옵션은 무엇인가요?”

“현재 조회되는 재고는 얼마나 되나요?”

2. 미팅 진행 시 추가 데이터 확인 사항

  • 업무 우선순위반복적으로 발생하거나 확인에 시간이 많이 걸리는 문의는 무엇인지
  • 필요 정보문의 처리 시 반드시 확인하는 데이터와 현재 사용하는 조회 경로는 무엇인지
  • 실무 테스트실제 문의 사례로 조회 결과의 정확성과 답변 초안의 활용도를 확인
  • 추가 요구사항현재 정리된 기능 외에 필요한 조회 항목이나 불편 사항 확인

3. 실제 사용 예제 · 이렇게 활용하세요

실제 프롬프트 사용 결과입니다. 평소 말투로 질문한 뒤, 조회된 정보를 확인하여 업무에 활용하세요.

01질문 입력주문번호·상품명·기간 등 조회 조건을 함께 입력하세요.
02조회 결과 확인주문 상태, 배송 정보, 리뷰 요약 등 필요한 내용을 확인하세요.
03업무에 활용추가 질문으로 범위를 좁히고, 확인된 정보를 고객 응대에 활용하세요.
EXAMPLE 01

주문 상태를 한 번에 확인해요

주문번호로 질문하면 결제 상태, 결제금액, 상품, 송장 등록 여부 등 주문 정보를 확인할 수 있습니다.

이렇게 질문하세요 · 입력 예시

“주문번호 20260914-0000031 지금 상태 어때? 배송 나갔어?”

확인 포인트: 결제 여부와 송장 등록 여부를 확인하세요. 출고 예정일은 별도로 확인한 뒤 안내합니다.

EXAMPLE 02

최근 리뷰와 고객 반응을 살펴봐요

최근 리뷰를 질문하면 조회 기간, 리뷰 건수, 평균 평점과 주요 리뷰 내용을 함께 확인할 수 있습니다.

실제 입력 질문

“최근 리뷰 뭐 올라온거있어?”

이어서 질문하기: “최근 2주 리뷰에서 반복적으로 언급되는 내용을 정리해 주세요.”

위 이미지는 사용 당시의 조회 결과입니다. 조회 시점과 조건에 따라 결과가 달라질 수 있습니다.

4. 업무별 상세 사용 가이드

01주문 상태 확인

주문번호를 기준으로 자사몰·스마트스토어 주문을 조회합니다.

  • “주문번호 ○○ 지금 상태 어때?”
  • “이 주문 배송 나갔어? 송장번호 알려줘.”
  • “주문번호 ○○ 취소된 거야, 결제된 거야?”

확인 정보
채널, 주문일, 결제·취소·배송·구매확정 상태, 금액, 쿠폰·적립금, 상품, 송장번호

02정책·규정 확인

고객 안내 전 공식 정책과 셀프가이드에서 답변 근거를 확인합니다.

  • “반품하면 쓴 쿠폰은 어떻게 돼?”
  • “제주도 배송비 규정 알려줘.”
  • “커버 세탁 방법 정책 찾아줘.”
  • “셀프가이드에서 비회원 쿠폰 사용 검색해줘.”

확인 정보
공식 정책 게시판 및 CS 셀프가이드 FAQ 원문(가이드 기준 304건). 근거가 확인되지 않으면 담당자 확인 후 안내합니다.

03답변 초안 작성

공식 정책과 과거 답변 사례를 참고하여 초안을 작성합니다.

  • “배송 지연 문의에 예전엔 어떻게 답변했어?”
  • “이 문의 답변 초안 잡아줘: 롤 커버 색상이 사진이랑 달라요.”
  • “교환 접수 안내 문구 만들어줘.”

활용 결과
기존 답변의 말투와 형식을 참고한 초안. 고객 안내 전 내용과 정책 근거를 검토합니다.

04미답변 문의 확인

자사몰·스마트스토어의 미처리 문의를 확인합니다.

  • “미답변 문의 있어?”
  • “자사몰 답변 안 남긴 문의만 보여줘.”
  • “최근 3일 미답변 문의 체크해줘.”

확인 정보
답변하지 않은 원글 목록 및 작성자 마스킹 정보

05고객 반응·리뷰 확인

최근 리뷰와 문의 내용을 확인하여 고객 반응을 파악합니다.

  • “최근 리뷰 뭐 올라왔어?”
  • “요즘 A/S 문의 뭐가 많아?”
  • “최근 2주 Q&A 게시판 정리해줘.”

확인 정보
상품 후기·Q&A·A/S 최근 글 요약, 리뷰 평점 분포·평균, 작성자 마스킹 정보

06오프라인 매장 배송 조회

매장에서 발송한 택배 내역과 배송 상태를 확인합니다.

  • “롯데안산 매장 어제 발송 건 보여줘.”
  • “주문번호 ○○ 배송 어디까지 갔어?”

확인 정보
배송 상태, 택배사, 송장번호, 발송일, 상품 및 고객명 마스킹 정보

07재고·품절 확인

조회 목적에 맞게 재고 종류를 구분합니다.

  • “자사몰에서 맥스 커버 품절 옵션 뭐야?”
  • “맥스 커버 재고 얼마나 남았어?”
  • “스토어 재고 10개 이하 상품 알려줘.”

확인 정보
자사몰 진열 재고 / 창고 실물 재고 / 스마트스토어 등록 재고

5. 사용 시 참고 사항

질문 및 답변 확인

  • 주문번호·상품명·기간을 함께 입력합니다. 예: “지난주”, “최근 3일”.
  • 정책 답변은 공식 원문을 확인한 후 안내합니다. 검색 결과가 없다는 이유만으로 실제 정책이 없다고 단정하지 않습니다.
  • 원본 가이드상 고객 개인정보는 제외 또는 마스킹됩니다. 이름·연락처·주소 확인이 필요한 경우 판매자센터 또는 관리자 화면을 이용합니다.
