CS팀 전용 — Claude(MCP)로 물어보는 법

Claude 데스크탑에 평소 말투로 물어보면 됩니다. 도구 이름을 외울 필요 없이 아래 예시처럼 질문하세요.
모든 답변은 회사 실제 데이터·공식 정책 원문 기준이며, 고객 개인정보(이름·연락처·주소)는 나오지 않습니다.

────────────────────────────────────────
1. 주문 상태 확인 — "이 주문 어떻게 됐어?"

주문번호만 있으면 자사몰·스마트스토어를 한 번에 조회합니다.

- 주문번호 20260910-0001234 지금 상태 어때?
- 이 주문 배송 나갔어? 송장번호 알려줘 (+ 주문번호)
- 주문번호 ○○ 취소된 거야, 결제된 거야?

→ 채널·주문일·상태(결제/취소/배송중/배송완료/구매확정)·금액·쿠폰/적립금·상품·송장번호

2. 정책·규정 확인 — 답변 근거 찾기 (추측 금지)

고객 문의에 답하기 전, 공식 정책을 확인하세요. 두 소스가 있습니다.

- 반품하면 쓴 쿠폰은 어떻게 돼?
- 제주도 배송비 규정 알려줘
- 커버 세탁 방법 정책 찾아줘
- 셀프가이드에서 비회원 쿠폰 사용 검색해줘 (CS 셀프가이드 FAQ 304건)

→ 공식 정책 게시판 + CS 셀프가이드 FAQ 원문. 원문에 없는 정책은 답이 "없음"으로 나오니 임의 안내 금지.

3. 답변 초안 작성 — 과거 사례로 톤 맞추기

- 배송 지연 문의에 예전엔 어떻게 답변했어?
- 이 문의 답변 초안 잡아줘: "롤 커버 색상이 사진이랑 달라요"
- 교환 접수 안내 문구 만들어줘

→ 공식 정책 확인 + 과거 실제 답변 사례의 톤·포맷을 반영한 초안

4. 미답변 문의 챙기기 — "답변 놓친 거 있어?"

- 미답변 문의 있어? (자사몰+스마트스토어 한 번에)
- 자사몰 답변 안 남긴 문의만 보여줘
- 최근 3일 미답변 문의 체크해줘

→ 답변 안 단 원글 목록 (작성자 마스킹)

5. 고객 반응·리뷰 보기 — "요즘 뭐라 그래?"

- 최근 리뷰 뭐 올라왔어? (평점 분포·평균 포함)
- 요즘 A/S 문의 뭐가 많아?
- 최근 2주 Q&A 게시판 정리해줘

→ 상품후기/Q&A/A/S 최근 글 요약 (작성자 마스킹, 본문 요약)

6. 배송 조회 (오프라인 매장 택배)

- 롯데안산 매장 어제 발송 건 보여줘
- 주문번호 ○○ 배송 어디까지 갔어?

→ 상태·택배사·송장번호·발송일·상품 (고객명 마스킹)

7. 재고·품절 확인 — "이거 언제 들어와요?" 문의 대응

- 자사몰에서 맥스 커버 품절 옵션 뭐야? (쇼핑몰 진열 재고)
- 맥스 커버 재고 얼마나 남았어? (창고 실물 재고)
- 스토어 재고 10개 이하 상품 알려줘 (스마트스토어 등록 재고)

→ 재고 3종 구분: 자사몰 진열 / 창고 실물 / 스토어 등록

────────────────────────────────────────
잘 쓰는 팁

- 주문번호·상품명·기간을 같이 주면 더 정확합니다. (예: "지난주", "최근 3일")
- 정책 답변은 반드시 2번으로 근거 확인 후 안내하세요. Claude가 원문에 없는 내용을 지어내지 않도록 되어 있어, "없음"이 나오면 실제로 공식 정책이 없다는 뜻입니다.
- 개인정보(이름·연락처·주소)는 MCP로 안 나옵니다. 필요하면 판매자센터/어드민에서 직접 확인하세요.

참고

- "셀프가이드 검색"(2번의 마지막)은 재배포 후 사용 가능합니다. 나머지는 지금 바로 됩니다.
- 데이터 기준: 주문·문의·재고는 실시간 조회, 매출/집계는 매일 오전 갱신값.
