# [안내] 전사 프로모션 등록 방식이 바뀝니다 — 엑셀 하나로 끝

기존처럼 대시보드에서 프로모션을 하나씩 등록하거나 목표를 따로 입력하지 않으셔도 됩니다.
**엑셀 한 파일에 정리해서 올리면**, 프로모션 정의와 목표매출이 한 번에 등록되고
**성과는 Claude에 물어보면 바로 나옵니다.**

---

## 1. 무엇이 달라지나요

| | 이전 | 이제 |
|---|---|---|
| 등록 | 대시보드에서 프로모션 건별 입력 | **엑셀 1개 업로드** |
| 목표 | 별도 화면에서 따로 입력 | **같은 엑셀에 목표매출 컬럼** |
| 성과 확인 | 화면 찾아 들어가기 | **Claude에 물어보기** |

> 그동안 자사몰 프로모션 매출이 **0원으로 나오던 문제**도 함께 해결했습니다.
> (자사몰이 즉시할인으로 바뀌면서 쿠폰 기준 집계가 안 잡히던 문제 → 대상상품 기준으로 변경)

---

## 2. 올리는 방법 — 3단계

**판매분석 대시보드 → 상단 `📄 프로모션 등록`**

1. **`⤓ 예제 양식 받기`** — 어떤 형식인지 보여드립니다
2. **엑셀 작성 후 올리기** — 파일 선택 또는 드래그앤드롭
3. **변경 내용 확인 → `이대로 반영하기`**
   - 올리면 먼저 **신규 / 수정 / 삭제 / 변동없음** 건수를 보여드립니다
   - 확인 후 누르셔야 실제로 반영됩니다
   - 잘못 올리셨으면 **`↺ 되돌리기`**로 직전 상태 복구 가능

---

## 3. 엑셀 작성법

### 꼭 채워야 하는 것

| 컬럼 | 설명 |
|---|---|
| `promo_id` | 프로모션 ID (예: `202607-01`) |
| `mall` | `자사몰` / `스마트스토어` / `오프라인` |
| `name` | 프로모션명 |
| `start` / `end` | 시작일 / 종료일 (`2026-07-03` 형식) |

**한 프로모션이 3개 몰에서 진행되면 3행으로** 적어주세요. (몰마다 한 행)

### 넣어주시면 좋은 것

| 컬럼 | 설명 |
|---|---|
| `target_sales` | **목표매출(원)** — 넣으시면 성과 조회 시 달성률이 함께 나옵니다 |
| `target_scope` | 대상범위: `전제품` / `제품군` / `품목` |
| `target_include` | 대상상품 — 세미콜론(`;`)으로 구분<br>예: `커버 전품목; 비즈 전품목; 트레이보 엑스` |
| `target_exclude` | 제외할 상품 |
| `disc_S` `disc_P` `disc_PP` `disc_cover` `disc_bead` | 할인율(%) |

**대상범위가 `전제품`이면 `target_include`는 비워두세요.** (전 상품이 대상)
특정 상품만 빼고 싶으시면 `target_exclude`에 적으시면 됩니다.

### 편하게 하셔도 되는 것

- **컬럼 순서 바뀌어도 됩니다** — 이름으로 읽습니다
- **필요 없는 컬럼이 더 있어도 됩니다** — 무시합니다
- **띄어쓰기 달라도 됩니다** — `코지보트래블` / `코지보 트래블` 둘 다 인식

## ⚠️ 한 가지만 주의해 주세요

**올리신 엑셀이 기준이 됩니다 (전체 교체).**

엑셀에 없는 프로모션은 **삭제**됩니다. 일부만 수정하실 때도
**전체 목록이 담긴 엑셀**을 올려주세요.

> 걱정하지 않으셔도 되는 이유:
> 반영 전에 **"삭제 N건"**을 보여드리고, 삭제가 있으면 한 번 더 확인을 받습니다.
> 그래도 잘못됐다면 **되돌리기**로 복구할 수 있습니다.
